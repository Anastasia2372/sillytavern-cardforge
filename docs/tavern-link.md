# 酒馆 Link

入口：侧栏「导出 → 酒馆 Link」。仅桌面端提供，修改主进程后需要退出并用 BAT 重新启动 CardForge。

1. 先启动 SillyTavern。默认地址为 `http://127.0.0.1:8000`，本机安装目录为 `E:\SillyTavern`。
2. 点击「连接 / 刷新」，选择酒馆已有角色或世界书。
3. 「载入到当前卡」用于从酒馆读取后编辑；会显示替换范围并要求确认。
4. 「更新酒馆角色」同步基础设定、开场白和提示词；可另选内嵌世界书、正则和助手脚本。角色的头像、聊天文件名、收藏及独立世界书绑定不会被覆盖。
5. 「更新酒馆世界书」替换选中的独立世界书条目，包括分隔栏标记。可点「读取关联世界书」选择当前角色绑定的独立世界书。
6. 手动更新成功后，可开启相应目标的自动同步。停止编辑 2 秒后写回，切换当前卡或目标、连接失败或检测到冲突时关闭。该开关不会跨重启自动恢复。

角色内嵌世界书和酒馆独立世界书是两个存储位置。更新前者不等于更新角色当前绑定的独立世界书；后者需要单独选择并同步。Link 不自动改变全局世界书启用设置，不创建新角色或新世界书。

支持当前本机免登录配置。CSRF 令牌和会话 Cookie 由连接层正常获取，无需关闭酒馆 CSRF 或修改 CORS。账号登录及 Basic Auth 暂不支持。

酒馆现有 HTTP 接口不向已打开页面推送更新事件，因此保存后可能需要刷新酒馆页面或重新载入角色/世界书。请避免同时在酒馆页面和 CardForge 修改同一个目标：Link 会做写前冲突检查和写后读回，但酒馆接口不支持原子的版本锁。

请求失败会停止自动同步。若写入请求超时，服务端可能已经保存，请重新读取确认实际结果后再继续。
